תיאור כללי: אפליקצת דפדפן לסוכנות רכב zeker, המאפשרת למתחברים להתחבר, להרשם להלות מסמכים לפיירבס והעלות מסמכים , פרטי יצירת קשר, נתוני משתמש, נתוני רכב ונתוני מסמך לבסיס נתונים מוג מונגו
## Technologies
- React
- Node.js
- Express
- MongoDB
- Firebase Authentication
- Firebase Storage
- Google Maps API
- NodeMailer

## Main Features
- User registration and login
- Vehicles / services display
- Vehicle / service details page
- File upload
- Contact form
- Email sending
- Google Maps integration
